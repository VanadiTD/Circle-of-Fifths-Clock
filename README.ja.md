# CIRCLE OF FIFTHS CLOCK

[English](README.md) | **日本語**

https://vanaditd.github.io/Circle-of-Fifths-Clock/

シェパードトーンで鳴る「5度圏時計」です。今の時刻に合わせて3本の針が回り、音の高さは止まることなく上がり続けます。スマホのブラウザで開くことを想定した、1ファイルだけの HTML 作品です。

白いスタジオの壁に、黒いガラスの時計と大きなステレオスピーカーが埋め込まれています。手前にはモジュラーシンセ、上には音を映すモニターがあります。

---

## 使い方

1. `index.html` をブラウザで開きます。GitHub Pages で公開すれば、URL を開くだけで動きます。
2. シンセの **PLAY** ボタンをタップすると音が鳴り始めます。もう一度タップすると止まります。
   - 初めて開いたときは、ボタンの上に **TAP TO PLAY** の吹き出しが出ます。この吹き出しをタップしても再生できます。
   - ブラウザの決まりで、画面を一度タップするまで音は出せません。
   - ボタンの輪は、再生中は緑、停止中は赤(ゆっくり明滅)です。
   - 再生・停止のときは、音が0.3秒かけてフェードイン/フェードアウトします。
3. シンセのパネルをタップすると、そのモジュールに寄って、つまみやスイッチを操作できます。
   - 横にスワイプすると隣のモジュールへ移ります。
   - **BACK** で全体の画面に戻ります。
4. 壁のモニターをタップすると、詳しいメーター画面(**SCOPE**)が開きます。
5. 左上のデジタル時計をタップすると、時刻を選んで好きな時間へ飛べます。**NOW** を押すと今の時刻に戻ります。

カメラは正面に固定です。指で視点を動かすことはできません。

### 動作環境

- WebGL2 と Web Audio に対応したブラウザ(最近の iPhone / Android / PC の Chrome・Safari・Edge・Firefox)
- イヤホンかステレオスピーカーで聴くと、針の位置による左右の動きがわかります

## 音のしくみ

### 5度圏は「目盛り」

文字盤には5度圏の順に音名が並んでいます。

`C – G – D – A – E – B – F# – C# – Ab – Eb – Bb – F`

ただし、針が音名を指したときだけその音が鳴るわけではありません。音名と音名のあいだも周波数をなめらかにつないでいるので、**音の高さは常に上がり続けます**。たとえば C から G へ進むあいだは、C と G の周波数を 1:4、2:3 … と内分した高さを順に通ります。

### シェパードトーン

1つの音は、オクターブ違いの7つの成分を重ねて作っています。高い成分ほど静かに消え、低いところから新しい成分がそっと入ってきます。このため、ずっと上がり続けているのに音域は外へ出ていかない、という錯覚が生まれます。

基準のピッチは **A4 = 440 Hz** で固定です。

### 3本の針の役割

| 針 | 長さ | 役割 |
|---|---|---|
| 秒針 | いちばん長い | 鳴っている音そのもの。**TICK**(1秒ごとに鳴る)か **DRONE**(鳴り続ける)を選べます |
| 分針 | 中くらい | 秒針の音に **AM(振幅変調)** をかけます |
| 時針 | いちばん短い | 同じく秒針の音に **AM** をかけます |

AM は「音量を周期的に揺らす」変調です。揺れの中心は元の音量のままなので、**基音は必ず残ります**。

- **AUDIO**(初期設定):分針・時針の位置の高さ(可聴域の周波数)で揺らします。音色そのものが変わり、金属的な響きになります。
- **SLOW**:数Hz以下のゆっくりした揺れ(トレモロ)になります。

### 左右の定位(パン)

針の先端の位置とカメラの位置から、音の左右を計算しています。針が時計の右側にあれば右のスピーカーから、左側にあれば左から聞こえます。3本の針はそれぞれ別に定位します。

## 画面の見かた

| 場所 | 内容 |
|---|---|
| 左上 | デジタル時計と、各針がいま指している音名(`HOUR · MIN · SEC`)。タップすると時刻を選べます |
| 右上 | タイトル |
| 壁のモニター | 左から **SPECTROGRAM**(時間ごとの周波数)、**SPECTRUM**(周波数ごとの強さ)、**WAVEFORM**(波形) |
| 時計 | 針が通るところの LED が光ります |
| 手前のシンセ | 操作パネル(下の表) |
| 画面下の **▴ METERS** | 小さなメーターの引き出し。初期状態では閉じています |

### 下の引き出し(METERS)

- **▶ PLAY**:再生・停止
- **SCOPE**:詳しいメーター画面を開く
- **CONTROL**:シンセの操作画面に寄る
- **▾**:引き出しを閉じる

### SCOPE(詳細画面)

モニターの3つの表示を大きく、目盛りと数値付きで確認できます。**CLOSE** で閉じます。

## シンセの操作パネル

左から5つのモジュールが並んでいます。いちばん左はロゴのパネルで、操作できるのは残りの4つです。

### ロゴ(いちばん左)

**1void_** のロゴと、作品名 **Circle of Fifths Clock** のパネルです(文字は Inter)。操作する部品はありません。

### SECONDS

| 操作 | 内容 | 範囲 / 初期値 |
|---|---|---|
| スイッチ **TICK / DRONE** | 秒針の鳴り方 | 初期値 DRONE |
| つまみ **DECAY** | TICK のときの余韻の長さ | 0.08〜1.5 秒 / 0.5 秒 |

### AM

| 操作 | 内容 | 範囲 / 初期値 |
|---|---|---|
| つまみ **HOUR** | 時針による AM の深さ | 0〜100% / 60% |
| つまみ **MIN** | 分針による AM の深さ | 0〜100% / 60% |
| スイッチ **SLOW / AUDIO** | AM の速さ | 初期値 AUDIO |

### TRANSPORT

| 操作 | 内容 | 範囲 / 初期値 |
|---|---|---|
| **PLAY**(大きいボタン) | 再生・停止(輪が緑=再生中、赤=停止中) | — |
| **NOW** | 飛ばした時刻を今の時刻に戻す(速さはそのまま) | — |
| つまみ **SPEED** | 時間の進む速さ | ×1〜×120 / ×1 |
| つまみ **JOG** | 時刻を前後に飛ばす。上へドラッグで進む、下で戻る(180px ≒ 1時間) | — |
| 表示 | 速さと、時計が示している時刻 | — |

- SPEED は ×60 あたりが回しやすいように、低い倍率ほど細かく動くようにしてあります。速くすると、針の動きと音の上昇が早送りになります。
- JOG の赤い印は、分針と同じく1時間で1周します。
- 遠くの時刻へ一気に飛びたいときは、左上のデジタル時計をタップして時刻を選びます。

### MONITOR

各針の位置・周波数・左右の定位を数字で表示します。下の3つのジャックから、壁へケーブルが伸びています。

## 技術メモ

- **1ファイル完結**:`index.html` の中に、シェーダー・音声処理・音名とロゴのフォントのデータがすべて入っています。サーバーは不要です。パネルの見出しと数値の文字(Barlow Condensed / Share Tech Mono)だけは Google Fonts から読み込み、オフラインのときは代わりのフォントで表示します。
- **映像**:WebGL2 のレイマーチング(距離関数)で、スタジオ全体を1枚のシェーダーで描いています。
- **軽くする工夫**:カメラが固定なので、止まっている部分は開いたときに一度だけ描いて保存し、毎フレームはそれを表示するだけにしています。描き直すのは動く部分だけです。
  - 時計の針と LED
  - モニターの映像
  - 触ったパネル
- **ケーブル**:重力でたわむロープとしてあらかじめ計算した形を埋め込んでいます。
- **音名の文字**:Inter の字形を「輪郭までの距離」の画像に変換して埋め込み、シェーダーで丸い断面の金属文字として立ち上げています。
- **音**:Web Audio API。シェパードトーン(7成分)、時針・分針の AM、左右の定位、音割れ防止のリミッター、再生・停止のフェード(0.3秒)の順につないでいます。
